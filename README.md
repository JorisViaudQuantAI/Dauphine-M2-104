# 🎓 Examen Final : Data Management & Machine Learning

Bienvenue dans l'épreuve finale du cours de Data Management. Cet examen pratique a pour but d'évaluer votre capacité à mener un projet de Data Science de bout en bout : du chargement des données brutes à la modélisation prédictive.

**Durée :** 2 heures  
**Support :** Jupyter Notebook (Python)

---

## 🚀 Contexte & Mission

Vous avez accès à un jeu de données concernant un incident survenu lors du voyage inaugural d'un vaisseau spatial interstellaire. Une anomalie a provoqué la disparition d'une partie des passagers.

**Votre objectif :** En tant que Data Scientist, vous devez analyser les données récupérées du système de bord pour comprendre les facteurs qui ont influencé cet événement et **construire un modèle de Machine Learning capable de prédire quels passagers ont été affectés par l'anomalie.**

Le sujet détaillé et les consignes spécifiques se trouvent dans le fichier notebook : `Sujet_Examen_Data_Management.ipynb`.
